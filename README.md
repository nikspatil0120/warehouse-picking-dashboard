\# Warehouse Picking Dashboard



A web-based dashboard for managing warehouse picking operations, including item catalogue, stock transactions, order status, search and filtering, and exception alerts.



\## Features (MVP)



\- Item catalogue management

\- Create and update stock transactions

\- Stock and order status tracking

\- Search and filtering

\- Exception alerts



\## Technology Stack



\- Java 17

\- Spring Boot 3

\- Maven

\- Thymeleaf

\- H2 Database

\- Apache Tomcat 10.1

\- JUnit 5

\- Selenium

\- Jenkins

\- Docker

\- Ansible
